Kết nối Chrome profile

Chọn đúng profile đang mở cửa sổ này. Xem Profile Path tại chrome://version: phần cuối là Default hoặc Profile 1, Profile 2… Mỗi profile cần cài extension và cấu hình một lần.

Khi chạy qua CLI/API, truyền chính thư mục profile đã chọn ở đây (ví dụ --profile "Profile 1"). Giữ Chrome và extension hoạt động để nhận các bước trình duyệt. Token API được cấu hình trong môi trường của agent và CLI.

Mở cấu hình điều khiển từ xa. Ghép nối và cấp quyền tại máy local; giữ Chrome profile cùng extension hoạt động để nhận các bước từ kịch bản remote.
