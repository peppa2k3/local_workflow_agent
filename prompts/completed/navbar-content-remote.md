# Navbar nội dung và remote

Yêu cầu: chuyển trực tiếp giữa quản lý nội dung và Remote Control trên navbar.

Thực hiện: navbar thống nhất trên ba trang local, trạng thái aria-current, focus bàn phím và bố cục mobile; giữ nguyên API và luồng ghép nối.

Hoàn thành: kiểm tra click chuyển qua cả ba trang ở 1280/390 px đạt; npm test đầy đủ, node --check tests/remote-web.js và git diff --check đạt.
