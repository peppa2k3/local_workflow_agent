Tạo kịch bản trực quan và chạy trên Chrome profile hiện có.

Đang kết nối agent...

Cài extension trong từng profile, mở Extension options và chọn đúng thư mục profile. Mỗi profile có thể chạy một kịch bản riêng.

CLI/API: node local-agent.js --help. Hướng dẫn cấu hình token trong docs/SETUP.md.

Kết quả tải: {{download_title}} = tiêu đề / tên phim; {{download_file_name}} = tên file; {{download_file_path}} = đường dẫn clip; {{download_id}} = ID. Dùng trong các bước sau downloadVideo.

Danh sách biến Tham chiếu bằng {{ten_bien}} trong các input. Khi chạy sẽ lấy giá trị hiện tại; JSON giữ tên tham chiếu.
